🤔 LLM เรียก Tool เองไหม?

คำตอบ

โปรแกรมนี้เป็นคนเรียก — LLM แค่บอก "ฉันอยากเรียก get_products('headsets')" กลับมาเป็น structured data แล้วโปรแกรม query SQLite จริง

สิ่งที่ LLM ส่งกลับมา

response.tool_calls = [
  { "name": "get_products", "args": {"category": "headsets"}, "id": "call_abc" }
]

โปรแกรมเรียก Python + query SQLite จริงใน chat_fn()

for tc in response.tool_calls:
    if tc["name"] in tool_map:
        result = tool_map[tc["name"]].invoke(tc["args"])   # → query keycraft.db
        current_messages.append(ToolMessage(content=str(result), tool_call_id=tc["id"]))

⚡ กรณีถามสินค้าหลายประเภทพร้อมกัน

tool เดียวรับ multiple calls ได้ — เมื่อถาม "มี keyboard และ headset อะไรบ้าง?" LLM เรียก tool 2 ครั้งในรอบเดียว 
response.tool_calls = [
  { "name": "get_products", "args": {"category": "keyboards"}, "id": "call_001" },
  { "name": "get_products", "args": {"category": "headsets"},  "id": "call_002" }
]

loop ใน chat_fn วนผ่านทุก tool_calls ก่อน invoke ครั้งถัดไป — ทำให้ไม่ต้องเพิ่ม tool ใหม่เมื่อมี category เพิ่มขึ้น

🗄️ DB Lifecycle

รันครั้งแรก (ไม่มี keycraft.db)
→ _init_db() เรียก
→ CREATE TABLE ✓
→ COUNT = 0 → INSERT 16 rows
→ "seeded 16 products"
รันครั้งถัดไป (มี keycraft.db)
→ _init_db() เรียก
→ CREATE TABLE IF NOT EXISTS (ข้าม)
→ COUNT = 16 → ไม่ seed
→ "loaded (existing data)"
Reset data: ลบไฟล์ keycraft.db แล้วรันใหม่ — โปรแกรมจะ seed ข้อมูลเริ่มต้นให้อัตโนมัติ
